## 알아 둘 것

- QA는 남의 PR을 구독하지 않고 리뷰만 남깁니다. 내 문서 PR은 구독하고, `docs/`를 바꾸면 머리 커밋에 `user-approved`가 있어야 머지합니다.
- 리뷰의 `commitID`는 `git ls-remote origin refs/pull/N/head`로 받은 전체 SHA를 씁니다.
- 보안 결함은 S0·S1이고, 재현 방법은 공개된 곳에 쓰지 않습니다(qa.md 4장). 위협 모델에는 고친 뒤의 막는 것만 적습니다.
- 알파 Caddy의 Trivy 예외(`infra/alpha/.trivyignore`)가 2026-12-04에 끝납니다. 그 전에 인프라가 Caddy를 올리고 HTTP/2를 다시 켜야 합니다(#158).
- 안드로이드 클립보드는 창이 포커스를 가질 때만 읽히고, 지우기는 뒤에서도 됩니다(AOSP `ClipboardService`). `getPrimaryClipDescription`은 토스트를 띄우지 않습니다(#141, #156).
- m1.md 2.6 대조는 표의 백틱 이름을 모두 뽑아 시험 소스(`core/*/tests`, `src`의 Rust 시험, iOS·안드로이드 시험 폴더, `server/api/src/test`)에서 `git grep -F`로 찾는 방식으로 했습니다.
- 안드로이드 API 26–30의 `KeyStore.getKey`가 null이면 데몬 무응답일 수 있습니다. 읽을 때 키를 만들면 비밀을 모두 잃습니다(#63).
- 코어 오류 문구에 URL이 실리지 않게 reqwest 오류는 `without_url()`로 바꿉니다(#56, #71).
