# 아키텍처 결정 기록(ADR)

여러 선택지 중 하나를 고른 이유와 그 결정이 다른 직군에 미치는 영향을 남기는 곳입니다. 다시 볼 조건이 오기 전까지는 결정으로 봅니다.

- 파일 이름은 `NNNN-주제.md`이고 번호는 네 자리로 순서대로 붙입니다. 번호는 다시 쓰지 않습니다.
- 상태는 `제안`, `채택`, `폐기`, `대체됨(→ NNNN)` 중 하나이고, 결정을 바꿀 때는 기존 문서를 고치지 않고 새 번호로 쓴 뒤 옛 문서의 상태만 바꿉니다.
- 각 문서는 상태, 배경, 선택지, 결정, 근거, 영향, 다시 볼 때 순서로 씁니다. 문서는 한국어로, 코드 식별자와 크레이트 이름은 그대로 둡니다.
