# 디자인

그날어때 디자인 시스템 v0입니다. 화면 시안과 작동 흐름은 [시안 캔버스](https://claude.ai/artifact/3zAhdWP14DNVCW3dMDkhqY)에 있고, 이 문서와 [`tokens.json`](tokens.json)은 앱에 옮길 값을 정리합니다. 시안 캔버스는 비공개라서 볼 사람에게 공유해야 열립니다. 기능 규칙은 [개요](../kickoff.md) 5장을 따릅니다.

Apple 디자인의 절제(흰 바탕, 먹색 글자, 알약 버튼, 떠 있는 것에만 그림자)를 기초로 삼고, 색은 일정과 그룹, 그리고 그 시간에 비어 있는 사람 수에만 씁니다.

## 1. 원칙

| 번호 | 원칙 | 뜻 |
| --- | --- | --- |
| 01 | 일정이 주인공 | 화면은 흰 바탕과 먹색 글자로 물러납니다. 꾸밈용 그라데이션은 쓰지 않습니다. |
| 02 | 강조색은 내용마다 하나 | 내 캘린더의 버튼은 먹색, 그룹 안은 그룹 색이 맡습니다. 앱의 자리를 알려 주는 탭 막대만 브랜드 색 포도를 씁니다. |
| 03 | 색은 사람 수 | 그룹 캘린더의 진하기는 그 시간에 비어 있는 사람 수입니다. 0명은 비우고 판정하지 않습니다. |
| 04 | 탭 한 번이면 저장 | 추천 칩을 누르면 바로 저장하고 되돌리기를 띄웁니다. 확인 창으로 묻지 않습니다. |
| 05 | 떠 있는 것에만 그림자 | 시트, 토스트, 탭 막대만 그림자 하나. 나머지 층은 바탕색 차이로 나눕니다. |
| 06 | 안심은 한 줄로 | 암호화는 필요한 순간에 한 문장으로 알립니다. 자물쇠 아이콘을 곳곳에 붙이지 않습니다. |

## 2. 색

### 2.1 중립색

대비는 바탕(`background`) 기준입니다.

| 역할 | 토큰 | 밝은 모드 | 어두운 모드 | 쓰는 곳 |
| --- | --- | --- | --- | --- |
| 바탕 | `background` | `#ffffff` | `#000000` | 화면 |
| 묶음 바탕 | `groupedBackground` | `#f4f4f6` | `#1c1c1f` | 설정 목록, 카드, 시트 |
| 빈 칸 | `emptyCell` | `#f2f2f5` | `#161618` | 띠와 날 테이블의 0명 |
| 채움 | `fill` | `#ebebef` | `#2a2a2e` | 칩, 세그먼트 |
| 구분선 | `separator` | `#e1e1e6` | `#333338` | 1px 선 |
| 먹색 | `ink` | `#1b1b1f` (17.2:1) | `#f4f4f6` (19.1:1) | 글자, 내 캘린더의 주요 버튼 |
| 보조 글자 | `secondaryText` | `#5c5c66` (6.6:1) | `#b4b4bc` (10.2:1) | 설명 |
| 흐린 글자 | `tertiaryText` | `#696973` (5.4:1) | `#93939d` (6.9:1) | 시각, 꺼진 탭 |
| 일요일·공휴일 | `sunday` | `#c92f26` (5.4:1) | `#ff6b61` (7.5:1) | 달력 날짜 |
| 토요일 | `saturday` | `#2958c8` (6.3:1) | `#7aa2ff` (8.4:1) | 달력 날짜 |

### 2.2 그룹 색 12색 × 5단계

토마토, 귤, 겨자, 올리브, 숲, 민트, 하늘, 바다, 포도, 자두, 벚꽃, 코코아. 값은 `tokens.json`의 `color.group`에 있습니다.

- **단계는 비어 있는 사람 수입니다.** 0명은 빈 칸, 전원이 비면 5단계, 그 사이는 `min(4, 1 + floor((k - 1) × 4 / (n - 1)))`입니다. 10명 그룹이면 1~3명이 1단계, 9명이 4단계입니다.
- **만드는 법:** 한 색 안에서 색상(hue)을 고정하고 OKLab 명도만 같은 간격으로 나눕니다. 이웃 단계 명도 차는 0.06 이상, 1단계와 빈 칸의 명도 차는 0.05 이상입니다.
- **5단계는 그룹 대표색입니다.** 그룹 머리글, 버튼, 내 캘린더에 들어간 그 그룹 약속의 색으로 쓰고, 흰 글자를 4.6:1 이상으로 얹습니다. 두 모드에서 같은 색입니다.
- **1단계는 일부러 옅습니다.** 바탕 대비 약 1.4:1이라 색만으로 읽히지 않을 수 있습니다. 그래서 칸을 누르면 숫자와 이름이 나오고, 스크린 리더는 "14시, 1명 비어 있음"으로 읽습니다.

### 2.3 브랜드 색

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `brand.grape` | `#7d63cb` | 앱 아이콘, 브랜드 면(흰 글자 4.65:1) |
| `brand.tabText.light` | `#7152c4` | 선택한 탭의 아이콘과 글자(옅은 알약 위 4.84:1) |
| `brand.tabText.dark` | `#a898eb` | 어두운 모드의 선택한 탭(어두운 글라스 알약 위 4.73:1) |
| `brand.androidIndicator` | `#d9d4f8` | 안드로이드 내비게이션 바의 선택 인디케이터 |

브랜드 색은 탭 막대와 앱 아이콘에만 씁니다. 화면 안의 강조는 먹색과 그룹 색이 맡습니다. 포도 그룹의 5단계와 같은 색이지만, 탭 막대는 그룹 화면에서도 브랜드 색을 유지합니다.

## 3. 글꼴

- **Pretendard**를 iOS·안드로이드 앱에 함께 넣습니다. 400과 600 두 굵기의 정적 글꼴만 넣고, OFL-1.1 라이선스 전문을 앱에 포함합니다. 글꼴에 없는 문자(이모지 등)는 시스템 글꼴로 넘어갑니다.
- **숫자는 고정폭**으로 맞춥니다. 시각과 표가 흔들리지 않게 iOS는 `.monospacedDigit()`, 안드로이드는 `fontFeatureSettings = "tnum"`을 씁니다.
- **줄바꿈은 어절 단위**입니다. iOS는 `.hangulWordPriority` 줄바꿈 전략, 안드로이드는 API 33 이상에서 `lineBreakWordStyle`의 `phrase`를 쓰고, 두 플랫폼 모두 긴 제목으로 실기기에서 확인합니다.
- **글자 크기 설정을 따릅니다.** iOS는 `Font.custom(_:size:relativeTo:)`(또는 `UIFontMetrics`), 안드로이드는 sp를 씁니다. 글자가 커지면 날짜 칸의 띠와 날 테이블은 칸 대신 목록("14시, 3명 비어 있음")으로 바뀝니다.

| 단계 | 크기 · 굵기 · 자간 | 예 |
| --- | --- | --- |
| `largeTitle` | 32 · 600 · −2.5% | 탭 첫 화면 제목 |
| `title1` | 26 · 600 · −2.5% | 약속 날짜 |
| `title2` | 20 · 600 · −1.5% | 시트 제목 |
| `bodyStrong` | 17 · 600 | 목록 제목 |
| `body` | 17 · 400 · 행간 1.5 | 본문 |
| `secondary` | 15 · 400 | 보조 설명 |
| `caption` | 13 · 400 | 마지막으로 바꾼 사람 |
| `micro` | 11 · 600 | 시간 눈금, 탭 이름 |

## 4. 간격 · 모서리 · 층

- **간격:** 4의 배수(4, 8, 12, 16, 20, 24, 32, 48). 화면 가장자리는 16~20입니다.
- **모서리:** 막대·띠 4, 칸 8, 입력 12, 카드·시트 20, 버튼·칩은 알약(999).
- **층:** 평면은 바탕색 차이로 나눕니다. 떠 있는 것만 그림자 하나를 씁니다. 시트 뒤 흐림막은 `rgba(10,10,14,0.32)`입니다.

## 5. 내비게이션

화면 아래에 떠 있는 캡슐 두 개를 둡니다. 위는 다음 할 일 막대, 아래는 탭 막대입니다.

| 항목 | 값 |
| --- | --- |
| 탭 막대 | 높이 64, 좌우 16, 화면 아래에서 20, 모서리 32 |
| 다음 할 일 막대 | 높이 56, 탭 막대 위 8, 모서리 28 |
| 탭 | 캘린더 · 그룹 · 채팅 · 나. 아이콘 26, 이름 11 |
| 선택한 탭 | 브랜드 글자색 + 옅은 알약(밝은 `rgba(0,0,0,0.07)`, 어두운 `rgba(255,255,255,0.14)`) |
| 배지 | 그룹 탭은 응답할 일 수, 채팅 탭은 읽지 않은 메시지 수(알림을 끈 방은 빼고) |
| 보이는 곳 | 탭의 첫 화면(캘린더의 월·주·목록, 그룹 목록, 채팅 목록, 나)과 그룹의 캘린더·사진. 날 테이블·약속 상세·편집·시트·채팅방에서는 숨김 |

- **다음 할 일 막대:** 지금 이후 가장 가까운 일정을 보여 줍니다. ‹ ›로 이전·다음 일정을 시간순으로 넘기고, 가운데를 누르면 상세로 갑니다. 일정을 넣은 직후에는 이 자리에 "추가했어요 · 되돌리기"가 뜹니다.
- **iOS:** iOS 26에서는 `TabView`가 리퀴드 글라스를 그리고, 다음 할 일 막대는 `tabViewBottomAccessory`로 붙입니다. 선택 색은 `.tint`로 브랜드 탭 글자색을 줍니다. iOS 17·18에서는 기본 탭 막대에 같은 색 규칙만 적용하고, 막대는 탭 막대 위에 직접 얹습니다. 글라스 값(흰색 66%, 블러 16, 안쪽 하이라이트 1px)은 시안과 iOS 17·18 대체용입니다.
- **안드로이드:** Material 3 내비게이션 바(바탕 `#f4f4f6`). 선택 인디케이터 `#d9d4f8` 위 아이콘과 이름은 `#7152c4`, 나머지는 `#5c5c66`입니다.

## 6. 화면 시안

시안 캔버스의 페이지별 보드입니다. 휴대폰 보드는 390×844이고, 대부분 눌러서 다음 화면으로 넘어갑니다.

| 페이지 | 보드 |
| --- | --- |
| 기초 | 기초 원칙, 색, 글꼴·간격·컴포넌트, 작동 흐름, 앱 아이콘 초안 |
| M1 | 시작, 로그인, 권한, 월 캘린더, 빠른 입력, 추가됨, 주, 목록, 일정 편집, 교대 찍기, 사람·생일, 나, 복구 코드, 위젯 |
| M2 | 그룹 목록, 초대, 참여, 그룹 캘린더, 날 테이블, 날짜 잡기 시트, 약속 상세, 응답, 시간 투표, 정해짐, 그룹 설정, 그룹 캘린더(어두운 모드) |
| M3·M4 | 그룹 채팅, 사진 모아보기, 알림 문구, 플러스, 채팅 탭(방 목록), 사진·파일 보내기, 신고·차단 |

- **채팅 탭:** 그룹 방과 1:1을 최근 순으로 보여 줍니다. 1:1은 같은 그룹 멤버와만 시작하고, 기기 안에서만 검색합니다.
- **사진·파일 보내기:** 한 번에 3개, 파일당 10MB, 9가지 형식. 원본은 10MB 이하일 때만 고를 수 있습니다. 채팅은 서버에 30일, 약속과 내 일정 첨부는 1년 보관된다고 알립니다.
- **신고·차단:** 메시지를 길게 눌러 신고하면 고른 메시지만 기기에서 풀어 보낸다고 알립니다. 차단은 그룹 채팅에서는 내 화면에서 가리고, 1:1에서는 받지 않습니다. iOS의 민감 이미지는 가린 채 보여 줍니다.

## 7. 앱 아이콘 (초안)

브랜드 색 포도 위에 흰 모양 하나를 둡니다. 세 방향 중 **B 말풍선 달력**을 권합니다. "그날 어때?"라고 묻는 말풍선 안에 고른 날 한 칸을 넣어 캘린더와 채팅을 한 모양에 담고, 29px에서도 말풍선과 점 하나로 읽힙니다. A(띠 달력)는 작게 보면 다섯 단계가 뭉개지고, C(글자 "날")는 흔하고 획이 많습니다.

- **원본:** 1024×1024 정사각형. 모서리는 시스템이 깎으므로 꽉 채웁니다.
- **iOS 26:** Icon Composer에 배경과 전경 두 층으로 넣어 기본·어두운·맑은·색조 모습을 만듭니다.
- **안드로이드:** 적응형 아이콘 108dp 두 층. 말풍선은 가운데 지름 66dp 안에 두고, 단색 층을 더해 테마 아이콘을 지원합니다.
- **스토어:** App Store 1024×1024(투명 없음), Google Play 512×512 PNG.

## 8. 토큰과 검사

`tokens.json`은 색, 글꼴, 간격, 모서리, 글라스, 내비게이션 값을 담습니다. 키 이름은 플랫폼 코드의 이름으로 그대로 옮길 수 있게 영어로 두었습니다.

```
python3 docs/design/palette.py           # 토큰 검사. 하나라도 어기면 종료 코드 1
python3 docs/design/palette.py --ramps   # 그룹 색 12×5를 다시 만들어 출력
```

검사하는 것:

- 그룹 색이 생성 규칙과 같은지, 명도 순서, 이웃 단계 명도 차, 5단계 위 흰 글자 대비, 1단계와 빈 칸의 차이
- 글자색 다섯 가지가 바탕과 묶음 바탕 위에서 4.5:1 이상인지(두 모드)
- 브랜드 색: 흰 글자, 탭 글자(빈 화면과 내용이 비치는 글라스 위), 안드로이드 이름과 인디케이터 위 아이콘(그래픽 기준 3:1)
- 사람 수 → 단계 규칙

색을 바꿀 때는 `palette.py`의 `HUES`·`MODES`를 고치고, `--ramps` 출력을 `tokens.json`에 옮긴 뒤 검사를 통과시키고, 시안 캔버스의 색 보드도 같이 고칩니다.

## 9. 확정이 필요한 것

계획상 디자인은 Claude 시안, 사용자 확정입니다. 아래는 확정 전입니다.

- 앱 아이콘 방향(B 권함)
- 1단계의 옅은 대비(1.4:1)를 탭·스크린 리더 보완과 함께 받아들일지
- 브랜드 색 포도를 탭 막대와 아이콘에만 쓰는 범위
