# 활동 카테고리 사전(초안)

날짜 잡기의 활동 추천([개요](../kickoff.md) 5.4)과 그룹 프로필의 취향 태그([M2](m2.md) 19번)가 함께 쓰는 사전입니다. 개요 10장의 미결정 사항으로, M2 시작 전에 사용자가 값을 확정합니다. 확정되면 코어가 사전을 내장하고, 바꿀 때는 앱 업데이트로 바꿉니다([Rust 코어](../parts/rust-core.md)).

## 1. 항목 정의

| 항목 | 뜻 | 쓰는 곳 |
| --- | --- | --- |
| 키 | 영어 소문자 식별자. 한 번 정하면 바꾸지 않습니다 | 취향 태그, 최근 90일 활동 기록(novelty) |
| 이름 | 화면에 보이는 이름. 투표 선택지와 약속 제목("그룹명 · 활동")에 들어갑니다 | 화면 |
| 시간대 | 시작할 수 있는 가장 이른 시각 ~ 끝나야 하는 가장 늦은 시각(한국 시간). 24시를 넘으면 다음 날 새벽(`26:00` = 다음 날 02:00) | timeFit |
| 요일 | 시간이 미정일 때 쓰는 요일 적합도. 평일(월~금) / 주말·공휴일, 0~1 | timeFit |
| 기본 길이 | 시간 추천이 이 활동으로 범위를 잡을 때 쓰는 길이 | 시간 추천, timeFit |
| 인원 | 참가자 수 최소~최대 | sizeFit |
| 실내·야외 | 실내, 야외, 둘 다 | 표시, 이후 날씨 반영 후보 |
| 비용 | 0 무료, 1 1인 1만 원 안팎, 2 1~3만 원, 3 3만 원 넘게 | 표시 |
| 지도 검색어 | 카카오맵 검색 링크의 카테고리 부분. `https://map.kakao.com/link/search/<동네> <검색어>` | 정해진 활동의 "지도에서 찾기" |

timeFit은 시작 시각이 시간대의 시작 이후이고, 시작 + 길이가 시간대의 끝 이전이면 1, 아니면 0입니다(개요 5.4). 시간이 미정이면 약속 날의 요일 값을 씁니다.

### 값을 정한 근거

- **시간대:** 영업시간이 아니라 "이 시간에 시작하면 어색하지 않은가"입니다. 술·노래방·PC방·집 모임은 자정을 넘겨 끝나는 일이 흔해 `26:00`까지 둡니다. 시간 추천의 기본 범위(09:00–21:00, 그룹 설정)와는 따로 계산하므로, 시간 추천이 21시에 끝나도 술의 timeFit은 그 범위 안 시작이면 1입니다.
- **요일:** 반나절 이상 걸리는 것(등산, 드라이브, 당일 여행, 놀이공원)은 평일 0, 퇴근 뒤에도 하기 쉬운 것은 1, 그 사이는 0.5입니다.
- **인원:** 한 테이블·한 방·한 차에 들어가는 수를 기준으로 했습니다. 그룹 최대 20명이라 위쪽 끝은 12에서 자릅니다. 2명 미만은 약속이 아니므로 최소는 모두 2 이상입니다.
- **비용:** 지금은 표시만 하고 점수에 넣지 않습니다(개요 5.4의 식에 없음).

## 3. 검토할 결정

| 결정 | 초안 | 누가 |
| --- | --- | --- |
| 20개의 구성과 값 | 2장 표 | 사용자 |
| 취향 태그 값 | 좋아요 1, 싫어요 0. 고르지 않은 카테고리는 그 참가자를 평균·최솟값에서 뺍니다(개요 5.4 "태그가 없는 참가자는 평균에서 뺍니다"를 카테고리 단위로 적용) | 사용자, 코어 |
| `member_profile.tags`의 모양 | `{ 키: "like" \| "dislike" }`. 키는 2장의 영어 키로, 이름을 바꿔도 태그가 유지됩니다 | 코어(공통 계약 4장) |
| 사전에 없는 활동 | 멤버가 직접 쓴 활동은 사전 밖이라 novelty·태그 계산에 들어가지 않고, 지도 검색어는 쓴 글자 그대로 씁니다 | 코어 |
| 실내·야외와 비용의 쓰임 | M2는 표시만. 날씨·비용 반영은 출시 뒤 검토 | 사용자 |
