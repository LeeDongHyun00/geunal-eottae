# 컴포넌트

화면을 이루는 부품의 크기, 상태, 접근성 규칙입니다. 값은 [`tokens.json`](tokens.json)의 `component`·`motion`·`a11y`에 같은 이름으로 있고, 모양은 [글꼴·간격·컴포넌트 보드](screens/basis/03-type.png)에서 봅니다. 단위는 pt(dp)입니다.

플랫폼 컴포넌트를 먼저 쓰고, 이 문서는 그 위에 얹는 값만 정합니다. iOS는 SwiftUI 기본 컴포넌트에 토큰을 입히고, 안드로이드는 Material 3 컴포넌트에 토큰을 입힙니다. 두 앱이 꼭 같은 픽셀일 필요는 없고, 같은 크기·색·문구·동작이면 됩니다.

## 1. 공통 규칙

| 규칙 | 값 |
| --- | --- |
| 누를 수 있는 최소 크기 | 44×44. 보이는 모양이 작아도 누르는 영역은 44 |
| 누름 | 0.97배로 줄고 120ms에 돌아옴. 색은 바꾸지 않음 |
| 꺼짐 | 바탕 `fill`, 글자 `tertiaryText`. 흐리게(opacity) 하지 않음. 이유를 버튼 이름에 적음. 유일한 예외는 색을 바꿀 수 없는 카카오·Apple 로그인 버튼으로, 불투명도 0.4로 끔 |
| 초점(키보드·스위치 제어) | 바깥 2pt `ink` 테두리, 모서리는 컴포넌트와 같게 |
| 모서리 | 띠 4 · 칸 8 · 입력 12 · 카드·시트 20 · 알약 999 |
| 글자 크기 설정 | 글자가 커지면 높이가 따라 늘고, 가로로 넘치면 줄바꿈. 잘라 내지 않음 |
| 접근성 이름 | 아이콘만 있는 버튼은 이름을 붙임(예: "이전 할 일"). 색으로 뜻을 전하는 곳은 숫자나 이름을 함께 읽힘 |

## 2. 버튼

| 종류 | 높이 | 바탕 / 글자 | 글자 | 쓰는 곳 |
| --- | --- | --- | --- | --- |
| 주요 | 52 | 내 캘린더 `ink` / `background`, 그룹 안 그룹 색 5단계 / 흰색 | 17 · 600 | 화면 아래 한 개. 시작하기, 신청하기, 참여하기 |
| 보조 | 52 또는 44 | `fill` / `ink` | 17 또는 15 · 600 | 주요 버튼 옆. 자세히, 다음에 |
| 위험 | 52 | `fill` / `sunday` | 17 · 600 | 약속 취소, 차단, 계정 삭제. 바탕은 채우지 않음 |
| 글자만 | 44 | 없음 / `ink` | 17 · 400 | 취소, 나중에 할게요 |
| 작은 알약 | 36 또는 40 | `fill` / `ink` | 14 · 600 | 머리글의 초대 코드, 알아보기, 복사 |
| 아이콘 | 44×44 | 없음 | 아이콘 22~26 | 닫기, 검색, 더하기 |

- 가로는 안쪽 여백 16~22. 화면 아래 주요 버튼은 좌우 20을 두고 꽉 채웁니다.
- 주요 버튼은 한 화면에 하나입니다. 둘을 나란히 두면 왼쪽은 보조, 오른쪽은 주요이고 비율은 1 : 1.4입니다.

## 3. 칩

| 종류 | 높이 | 모양 | 동작 |
| --- | --- | --- | --- |
| 추천 칩 | 44 | 흰 바탕, `separator` 1pt 테두리, 왼쪽에 캘린더 색 점 8, 제목 15 · 600, 시간 15 `secondaryText` | 누르면 바로 저장 |
| 응답 칩 | 36 | 아바타 24 + 이름 + 응답. 수락은 `fill`, 다음에는 테두리만 | 정보만 |
| 선택 칩(반복, 필터) | 36 | 꺼짐 `fill`/`ink`, 켜짐 `ink`/흰색 | 토글. 단일 선택이면 라디오로 읽힘 |
| 상태 배지 | 24~26 | 그룹 색 1단계 바탕에 `ink` 글자 12 · 600, 또는 `ink` 바탕에 흰 글자 | 확정, 응답, 가안 |

## 4. 세그먼트와 스위치

- **세그먼트:** 바깥 `fill`, 높이 40, 안쪽 여백 2. 켜진 칸은 흰 바탕과 작은 그림자(`0 1px 3px rgba(0,0,0,0.12)`), 글자 14 · 600. 월·주·목록, 사진·파일, 시간·활동.
- **스위치:** 51×31, 손잡이 27. 켜짐은 내 캘린더 `ink`, 그룹 안은 그룹 색 5단계. 꺼짐은 `separator`. 이름은 줄 왼쪽 글자가 맡습니다.
- **체크박스:** 24×24, 모서리 6. 만 14세 확인처럼 동의에만 씁니다.
- **라디오:** 22×22 원, 켜짐은 `ink` 7pt 링. 신고 이유처럼 하나만 고를 때.

| 두 줄 | 60~72 | 제목 17 · 600, 설명 14 `secondaryText`. 그룹 목록, 채팅 목록, 사람 |
| 일정 줄(목록 보기) | 48 | 캘린더 색 점 8, 제목 17, 설명 14, 오른쪽 시각 17 고정폭 |
| 카드 | 84 이상 | `groupedBackground`, 모서리 20, 안쪽 여백 14~16. 그룹 목록 |

밀어서 지우기는 쓰지 않습니다. 지우기는 편집 화면 아래의 빨간 글자 버튼으로만 합니다.

## 6. 시트와 겹침

| 종류 | 값 |
| --- | --- |
| 시트 | 위 모서리 20, 손잡이 36×5 `#d1d1d6`, 안쪽 여백 위 8 · 좌우 20 · 아래 34(홈 인디케이터 포함). 뒤 흐림막 `rgba(10,10,14,0.32)` |
| 시트 높이 | 내용만큼. 빠른 입력 552, 날짜 잡기 740, 1:1 시작 724. 화면의 90%를 넘지 않음 |
| 토스트 | 높이 48, 모서리 14, `ink` 바탕 흰 글자 15 · 600, 오른쪽 "되돌리기". 탭 막대 위 8. 다음 할 일 막대가 있는 캘린더 탭에서는 그 막대 자리에 막대와 같은 유리 캡슐(56)로 뜸([M1 화면](m1.md) 6번). 5초 뒤 사라지고 되돌리기를 누르면 바로 닫힘 |
| 제안 카드 | 토스트 위 8, 다음 할 일 막대와 같은 유리 바탕, 모서리 24, 안쪽 여백 위 14 · 좌우 18·12 · 아래 12. 질문 15 · 600 + 오른쪽 버튼 두 개(44, 보조 · 주요). 10초 뒤 사라지고, 답하면 바로 닫힘. 스크린 리더가 켜져 있으면 저절로 닫지 않음 |
| 배너 | 흰 바탕 카드, 아이콘 + 두 줄 + 작은 알약 버튼. 복구 코드처럼 사용자가 닫을 때까지 남는 안내 |
| 길게 누르기 메뉴 | 너비 240, 줄 46, 흰 94% + 블러 20. 위험한 항목은 맨 아래 빨간 글자 |
| 모달 창(alert) | 쓰지 않음. 묻는 것은 시트로 |

## 8. 캘린더 부품

| 부품 | 값 |
| --- | --- |
| 월 날짜 칸 | 높이 88(내 캘린더) · 72~80(그룹). 날짜 13 · 600, 오늘은 `ink` 원에 흰 숫자 |
| 일정 막대 | 높이 16, 모서리 4, 캘린더 색 2단계 바탕에 `ink` 글자 11. 그룹 약속은 그룹 색 5단계에 흰 글자. 세 개가 넘으면 "+2" |
| 비어 있음 띠 | 높이 14~16, 모서리 3~4, 0–24시를 24칸(1시간) 또는 48칸(30분)으로 자른 선형 그라데이션. 6시간마다 흰 눈금 1pt. 칸 색은 그룹 색 0~5단계 |
| 날 테이블 | 30분 칸 너비 8~10, 줄 높이 36, 합친 줄이 위, 멤버 줄은 아바타 + 이름 |
| 선택 범위 | 띠 위에 `ink` 2pt 테두리. 양 끝 손잡이 20×44 |
| 주 보기 | 시간 축 1시간 48, 일정 블록 모서리 8, 왼쪽 캘린더 색 2pt |

띠와 날 테이블은 색만으로 뜻을 전하지 않습니다. 칸을 누르면 "14시 · 3명 비어 있음 · 지영, 민수, 서연"이 뜨고, 스크린 리더에는 같은 문장을 읽힙니다. 글자 크기를 가장 크게 하면 띠 대신 목록으로 바뀝니다.

## 9. 움직임

| 경우 | 길이 | 가속 |
| --- | --- | --- |
| 누름 | 120ms | ease-out |
| 시트 열기·닫기 | 320ms · 240ms | 스프링(감쇠 0.85) / ease-in |
| 토스트 | 나타남 200ms, 5초 뒤 사라짐 200ms | ease-out / ease-in |
| 제안 카드 | 나타남 200ms, 10초 뒤 사라짐 200ms | ease-out / ease-in |
| 탭 전환 | 없음(즉시) | |
| 월 넘기기 | 가로 밀기, 손을 따라감 | 스크롤 |
| 다음 할 일 넘기기 | 160ms 가로 밀림 | ease-out |
| 띠 색 바뀜(응답이 들어올 때) | 240ms 색 보간 | linear |

움직임 줄이기(iOS `Reduce Motion`, 안드로이드 애니메이션 끄기)를 켜면 밀림과 스프링을 없애고 페이드 120ms만 남깁니다.

## 10. 플랫폼 대응

| 이 문서 | iOS(SwiftUI) | 안드로이드(Compose · Material 3) |
| --- | --- | --- |
| 주요 버튼 | `Button` + `.buttonStyle(.borderedProminent)` + 모양 캡슐, tint 토큰 | `Button`(filled), `shape = CircleShape` 높이 52 |
| 보조 버튼 | `.bordered` + `fill` | `FilledTonalButton` |
| 위험 버튼 | `.bordered` + `sunday` 글자, `.destructive` 역할 | `FilledTonalButton` + `sunday` 글자 |
| 칩 | 직접 그림(`Capsule`) | `FilterChip` / `AssistChip` |
| 세그먼트 | `Picker` + `.segmented` | `SingleChoiceSegmentedButtonRow` |
| 스위치 | `Toggle` | `Switch` |
| 시트 | `.sheet` + `.presentationDetents([.height(…)])` + `.presentationDragIndicator(.visible)` | `ModalBottomSheet` |
| 토스트 | 직접 그림(overlay). 캘린더 탭은 `tabViewBottomAccessory` 안 | `Snackbar`(동작 "되돌리기") |
| 제안 카드 | 직접 그림(overlay) | 직접 그림(`Snackbar`는 동작이 하나뿐) |
| 탭 막대 | `TabView`(iOS 26 리퀴드 글라스), `tabViewBottomAccessory` | `NavigationBar`(M3) + 위에 막대 |
| 길게 누르기 메뉴 | `.contextMenu` | `DropdownMenu` |
| 목록 | `List`(.insetGrouped) | `LazyColumn` + `ListItem` |
| 햅틱 | 저장·찍기 `.light`, 되돌리기 `.rigid` | `HapticFeedbackType.LongPress` 대신 `Confirm` |

플랫폼이 다르게 그리는 것(뒤로 가기 제스처, 스크롤 바운스, 상태 표시줄)은 그대로 둡니다.
