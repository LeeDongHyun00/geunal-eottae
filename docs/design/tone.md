# 문구와 톤

앱에 보이는 모든 글의 규칙입니다. 버튼 이름, 설명, 빈 화면, 오류, 권한 요청, 알림 문구에 모두 적용합니다. 화면별 문구는 [M1 화면](m1.md)과 [화면 시안](screens.md)에 있고, 여기에는 그 문구를 만든 규칙과 용어를 적습니다. 코드의 문자열은 두 앱이 같은 문구를 쓰도록 이 문서를 기준으로 맞춥니다.

## 1. 목소리

그날어때는 일정을 대신 정리해 주는 **꼼꼼한 친구**처럼 말합니다. 짧게 말하고, 사람 이름과 숫자로 말하고, 겁주거나 조르지 않습니다.

| 규칙 | 이렇게 | 이렇게 하지 않음 |
| --- | --- | --- |
| 해요체로 짧게 | 5명 모두 비어 있어요 | 모든 멤버가 참석 가능합니다 |
| 사람 이름과 숫자로 | 지영은 이 시간에 일정이 있어요 | 일정 충돌 1건 |
| 결과를 먼저 | 카페 마감을 추가했어요 · 되돌리기 | 정말 저장하시겠습니까? |
| 사용자가 한 일을 그대로 | 수락 · 다음에 | 참석 · 거절 |
| 앱이 아니라 사람이 주어 | 내 캘린더에 들어갔어요 | 시스템이 일정을 생성했습니다 |
| 한 문장, 한 가지 | 고른 메시지만 운영자에게 보내요. | 신고 기능은 선택한 메시지를 암호화 해제 후 운영팀에 전송하며… |
| 느낌표와 이모지는 쓰지 않음 | 추가했어요 | 추가했어요! 🎉 |
| 안심은 필요한 순간에 한 줄 | 이 방의 대화는 멤버의 기기에서만 열려요 | 모든 화면에 자물쇠 아이콘 |

- **존대의 수위:** 설명과 결과는 "~해요", 버튼과 칩은 명사형("저장", "다음에")이나 동사 어간("보내기", "참여하기")입니다. "~하세요"는 할 일을 안내할 때만 씁니다("템플릿을 고르고 날짜를 누르세요").
- **외래어:** 캘린더, 그룹, 채팅, 위젯, 템플릿은 그대로 씁니다. 그 밖에는 우리말을 먼저 찾습니다(알림, 되돌리기, 모아보기, 가져오기).
- **영어 글자:** 고유명사(Apple, Google Play)와 단위(MB, px)만 씁니다. OK, Cancel 같은 영어 버튼은 쓰지 않습니다.

## 2. 용어

같은 것은 늘 같은 말로 부릅니다. 코드의 식별자와 1:1로 맞출 수 있게 영어 이름도 함께 둡니다.

| 우리말 | 영어(코드) | 뜻과 쓰임 |
| --- | --- | --- |
| 일정 | event | 내 캘린더의 항목. "스케줄", "이벤트"는 쓰지 않음 |
| 약속 | appointment | 그룹에서 날짜를 잡아 만든 일정. 수락하면 내 캘린더의 일정이 됨 |
| 날짜 잡기 | date-setting | 약속을 만드는 흐름. "일정 조율", "투표 만들기"는 쓰지 않음 |
| 신청 | propose | 주도자가 날짜 잡기를 시작하는 행동 |
| 수락 · 다음에 | accept · pass | 약속에 대한 응답 두 가지. "참석·불참", "거절"은 쓰지 않음 |
| 주도자 | leader | 신청한 사람. 넘길 수 있음 |
| 가안 · 확정 | tentative · confirmed | 첫 수락 전·후의 약속 상태 |
| 투표 · 독재 | vote · leader-decides | 시간과 활동을 정하는 두 방식. 설정 화면에서는 "주도자가 정해요"로 풀어 씀 |
| 비어 있음 | free | 일정이 없는 시간. "가능", "가용"은 쓰지 않음 |
| 띠 | strip | 날짜 칸의 0–24시 막대 |
| 날 테이블 | day table | 하루를 30분으로 나눈 표 |
| 그룹 색 | group color | 12색 중 하나. 색 이름은 토마토·귤·겨자·올리브·숲·민트·하늘·바다·포도·자두·벚꽃·코코아 |
| 소프트 캘린더 | soft calendar | 나에게만 보이고 그룹에는 비어 있는 시간으로 보이는 캘린더 |
| 기기 캘린더 | device calendar | iOS·안드로이드 캘린더에서 읽기만 하는 일정 |
| 교대 템플릿 | shift template | 근무 시간 묶음. "찍다"는 템플릿으로 날짜에 근무를 넣는 동작 |
| 사람·생일 | people | 이름과 생일 목록 |
| 추천 칩 | suggestion chip | 빠른 입력 시트의 제안 다섯 개 |
| 복구 코드 | recovery code | 12단어. "시드", "니모닉"은 쓰지 않음 |
| 암호화 백업 | encrypted backup | 기기 기록의 백업. "클라우드 저장"은 쓰지 않음 |
| 기기 바꾸기 | device change | 새 기기에서 복구 코드로 돌아오는 흐름 |
| 다음 할 일 | next up | 탭 막대 위 막대. 다가오는 일정과 약속 |
| 모아보기 | gallery | 그룹의 사진·파일 |
| 운영자 | operator | 신고를 검토하는 사람. "관리자", "고객센터"는 쓰지 않음 |
| 그날어때 플러스 | Plus | 유료 플랜 |

## 3. 패턴

### 버튼과 칩

- 주요 버튼은 결과를 말하는 한 단어나 두 단어입니다: 저장, 신청하기, 참여하기, 보내기 · 2. "확인"은 정보만 보여 주는 화면을 닫을 때만 씁니다.
- 위험한 동작은 빨간 글자(`sunday` 색)로 쓰고 바탕은 채우지 않습니다: 약속 취소, 일정 삭제, 차단, 계정 삭제.
- 보조 버튼은 "취소"가 아니라 하지 않는 동작을 적습니다: 다음에, 나중에 할게요, 괜찮아요.
- 개수는 가운뎃점 뒤에 둡니다: 보내기 · 3, 그룹 4개 · 20개까지.

### 확인 대신 되돌리기

저장·추가·찍기·차단은 묻지 않고 바로 하고, 토스트에 "되돌리기"를 둡니다. 되돌릴 수 없는 것(계정 삭제, 그룹 삭제, 약속 취소)만 시트에서 결과를 나열한 뒤 묻습니다. 묻는 제목은 "~할까요?"입니다.

```
카페 마감을 추가했어요                    되돌리기
태오님을 차단했어요                        되돌리기
```

### 빈 화면

무엇이 비어 있는지와 다음 행동 하나를 적습니다. 그림은 넣지 않습니다.

```
아직 일정이 없어요
날짜를 누르면 추천이 떠요.                 [오늘 일정 넣기]

잡힌 약속 없음
```

### 오류와 한계

이유와 할 수 있는 일을 한 문장씩. 오류 코드는 보이지 않습니다.

```
10MB를 넘어서 보낼 수 없어요
한 번에 3개까지 보낼 수 있어요
연결이 끊겼어요. 다시 연결되면 보낼게요.
지금은 저장만 해 두고, 연결되면 올릴게요.
```

- 기기에서 하는 일(일정 추가, 검색, 추천)은 오프라인에서도 되므로 오류를 내지 않습니다. 서버가 필요한 일(초대, 백업, 메시지)만 "연결되면"으로 말합니다.
- 입력이 모자라면 버튼을 끄고 버튼 이름에 이유를 적습니다: "이유를 골라 주세요", "보낼 것을 골라 주세요".

### 복구 코드

복구 코드는 사용자가 잃으면 안 되는 것이라 무게를 두되, 오류는 무엇이 틀렸고 무엇을 다시 보면 되는지만 말합니다. 단어 목록은 BIP39 한국어이고 NFC로 보여 줍니다.

| 상태 | 문구 |
| --- | --- |
| 단어가 목록에 없음 | 8번째 단어가 목록에 없어요. 종이에 적은 글자를 다시 봐 주세요. |
| 체크섬이 틀림 | 12단어의 조합이 맞지 않아요. 단어 하나가 다르거나 순서가 바뀌었을 수 있어요. 종이에 적은 순서대로 다시 확인해 주세요. |
| 백업이 안 풀림(기기 바꾸기) | 이 코드로는 백업이 열리지 않아요. 다른 계정의 코드이거나 단어 하나가 다를 수 있어요. |
| 계정을 못 찾음(게스트 복귀) | 이 코드로 계정을 찾지 못했어요. 게스트 계정의 코드인지, 카카오·Apple에 연결한 계정은 아닌지 확인해 주세요. |
| 가져올 백업 없음 | 가져올 백업이 없었어요. 일정은 이 기기에서 새로 시작하고, 이전 기기는 로그아웃됐어요. |
| 교체 티켓 만료 | 시간이 지나 처음부터 다시 로그인해 주세요. |
| 코드 없음(기기 바꾸기) | 복구 코드 없이는 되찾을 수 없어요 · 백업 없이 새로 시작 |
| 코드 없음(백업 가져오기 제안) | 복구 코드 없이는 백업을 열 수 없어요. 코드를 적은 종이가 집에 있다면 나중에 넣어도 돼요. · 나중에 넣을게요 · 캘린더부터 쓰기 · 백업 없이 새로 시작 |
| 지우기 확인 | 백업을 지우고 새로 시작할까요? 이 계정의 백업 3개(마지막 10월 20일 18:20)를 지우고, 새 복구 코드와 새 열쇠를 만들어요. 되돌릴 수 없어요. · 백업 3개 지우고 새로 시작 · 지우지 않을게요 |
| 지우기 확인(마지막 로그인 30분 지남) | 제목과 설명은 지우기 확인과 같음 · 카카오로 다시 확인하고 새로 시작(Apple 계정은 "Apple로 다시 확인하고 새로 시작") · 지우지 않을게요 |
| 새로 시작 확인이 다른 계정 | 이 계정에 연결된 카카오 계정으로 다시 확인해 주세요. 다른 계정으로는 새로 시작할 수 없어요. · 카카오로 다시 확인 |
| 복구 코드 대기(배너) | 복구 코드를 넣으면 백업을 가져와요 · 넣기 |
| 코드 없음(게스트) | 복구 코드 없이는 게스트 계정을 찾을 수 없어요 · 새 게스트 계정으로 시작 |
| 나이 확인 전 게스트 시작(토스트) | 만 14세 이상인지 확인하면 게스트로 시작할 수 있어요. |
| 다른 기기에서 로그인함(카카오·Apple) | 다른 기기에서 로그인했어요. 캘린더는 그대로 쓸 수 있어요. 내가 한 로그인이 아니라면 카카오·Apple 계정이 다른 사람에게 알려졌을 수 있어요. 그 계정의 비밀번호를 바꿔 주세요. |
| 다른 기기에서 들어옴(복구 코드) | 복구 코드로 다른 기기에서 들어왔어요. 내가 한 게 아니라면 복구 코드를 적은 종이를 누가 봤을 수 있어요. 다시 로그인한 뒤 카카오·Apple 계정을 연결해 두세요. |
| 다른 계정의 일정이 남음 | 이 기기에 다른 계정의 일정이 남아 있어요. 전에 이 기기를 쓰던 계정의 일정 86개, 사람 5명이에요. · 내 계정으로 가져오기 · 지우고 시작하기 |
| 카카오·Apple 계정 삭제 | 카카오 계정이라 ‘삭제’를 적은 뒤 카카오 로그인을 한 번 더 받아요. 세션만 훔친 사람이 계정을 지우지 못하게 하려는 거예요. · 카카오로 확인하고 삭제 |
| 삭제 재인증 실패 | 이 계정에 연결된 카카오 계정으로 다시 확인해 주세요. 다른 계정으로 로그인하면 지울 수 없어요. · 카카오로 다시 확인 |

버튼은 상태를 그대로 적습니다: "단어 5개 더", "8번째 단어를 고쳐 주세요", "코드를 다시 확인해 주세요", "다시 시도", "계정 찾기", "백업 가져오기".

### 알파 테스트 통계

숫자만 간다는 것을 한 문장으로 말하고, 무엇이 가지 않는지 바로 뒤에 붙입니다. 동의 버튼은 "보낼게요", 켜진 뒤에는 "보내요 · 나에서 끌 수 있어요"입니다.

```
테스트 통계 보내기 · 알파 빌드만
하루 한 번 숫자 네 개만 보내요: 앱을 연 횟수, 만든 일정 수, 그중 추천으로 만든 수, 비정상 종료 수. 제목·시간·이름은 가지 않아요.
```

나 화면의 스위치 설명은 "알파 빌드 · 하루 한 번 숫자 네 개만"입니다.

### 권한 요청

시스템 권한 창이 뜨기 전에 앱 화면에서 쓰는 곳과 한계를 먼저 말합니다. 거절해도 막히지 않고 설정에서 바꿀 수 있음을 적습니다.

| 권한 | 앱 화면 문구 | 시스템 권한 문구(iOS `Info.plist`, 안드로이드 rationale) |
| --- | --- | --- |
| 기기 캘린더 | 읽기만 해요. 가져온 일정의 제목은 이 기기 밖으로 나가지 않고, 그룹에는 비어 있는지만 보여요. | 기기 캘린더의 일정을 읽어 내 캘린더에 함께 보여 줘요. 제목은 이 기기 밖으로 나가지 않아요. |
| 알림 | 일정 알림, 친구의 날짜 잡기와 투표를 알려 드려요. 그룹마다 채팅·약속 알림을 따로 끌 수 있어요. | 일정 알림과 그룹의 날짜 잡기·투표 소식을 보내요. |
| 연락처 | 선택 기능이에요. 가져온 이름과 생일은 이 기기와 암호화 백업에만 있어요. | 연락처의 이름과 생일을 사람·생일 목록에 가져와요. 이 기기와 암호화 백업에만 저장돼요. |
| 사진 | 보낼 사진을 고르기 위해서예요. | 채팅과 일정에 붙일 사진을 골라요. |

### 날짜와 시간

| 경우 | 형식 | 예 |
| --- | --- | --- |
| 올해 날짜 | M월 D일(요일) | 11월 7일(토) |
| 제목으로 쓰는 날짜 | M월 D일 요일 | 11월 7일 토요일 |
| 다른 해 | YYYY년 M월 D일 | 2027년 1월 3일 |
| 가까운 날 | 오늘, 내일, 모레. 그 뒤는 날짜 | 내일(월) 10:00 |
| 시간 | 24시간, 콜론, 앞자리 0 | 09:00–18:00 |
| 시간 범위 | 엔 대시(–), 띄어쓰기 없음 | 19:00–21:00 |
| 시각 눈금 | 숫자만, 끝에 "시" | 0시 · 6 · 12 · 18 · 24시 |
| 종일 | "종일" | 11월 7일(토) · 종일 |
| 남은 시간 | 분 단위까지 두 단위 | 3시간 40분 뒤, 1분 전 |
| 생일 D-day | D-숫자, 당일은 "오늘" | D-5 |
| 음력 | 앞에 "음력", 올해 양력 날짜를 함께 | 음력 10월 3일 · 올해는 11월 11일 수요일 |
| 기간 | 주 단위 | 오늘부터 8주 |

- 일요일과 공휴일은 빨간 글자, 토요일은 파란 글자입니다. 달력 밖의 본문에서는 색을 쓰지 않습니다.
- 숫자는 고정폭으로 맞춥니다.

### 알림 문구

제목은 그룹 이름(개인 일정은 앱 이름 없이 일정 제목), 본문은 "보낸 사람: 내용"입니다. 기기에서 풀어서 보여 주므로 내용이 들어갑니다. 풀 수 없을 때의 자리표시는 "새 메시지가 있어요"입니다.

| 종류 | 제목 | 본문 |
| --- | --- | --- |
| 채팅 | 주말모임 | 지영: 다음 주 토요일 다들 시간 어때? |
| 날짜 잡기 신청 | 주말모임 | 하린: 11/7(토) 날짜 잡기 |
| 응답 | 주말모임 | 지영이 수락했어요 · 11/7(토) |
| 투표 열림 | 주말모임 | 시간 투표가 열렸어요 · 11/7(토) |
| 확정 | 주말모임 | 11/7(토) 19:00 보드게임 카페로 정해졌어요 |
| 변경(독재) | 가족 | 엄마: 시간을 13:00로 바꿨어요 · 11/15(일) |
| 일정 알림 | 가족 · 저녁 | 1시간 뒤 · 18:00–20:00 |
| 생일 | 민수 생일 | 오늘 · 축하 메시지 보내기 |

알림 안의 날짜는 짧게 `M/D(요일)`로 씁니다.

### 안심 문구

암호화는 그 정보가 처음 서버와 만나는 순간에 한 문장으로 알립니다. 이미 본 화면에서는 다시 말하지 않습니다.

| 순간 | 문구 |
| --- | --- |
| 시작 화면 | 일정과 대화는 멤버의 기기에서만 열려요 |
| 그룹 참여 | 30분 단위로 비어 있는지만. 일정 제목·장소·첨부는 보이지 않아요. |
| 기기 캘린더 권한 | 제목은 이 기기 밖으로 나가지 않아요 |
| 채팅방 첫 진입 | 이 방의 대화는 멤버의 기기에서만 열려요 |
| 검색 | 이 기기에 저장된 대화에서만 찾아요. 서버는 내용을 몰라요. |
| 신고 | 고른 메시지만 이 기기에서 풀어 운영자에게 보내요 |
| 복구 코드 | 이 12단어는 그날어때도 모릅니다. 코드와 기기를 함께 잃으면 되찾을 수 없어요. |

복구 코드처럼 사용자가 잃으면 안 되는 것은 예외로 "~합니다"체로 무게를 둡니다.

## 4. 쓰지 않는 말

| 쓰지 않음 | 대신 |
| --- | --- |
| 정말 ~하시겠습니까? | 바로 하고 되돌리기 / ~할까요? |
| 성공적으로, 완료되었습니다 | ~했어요 |
| 오류가 발생했습니다 | 무엇이 안 됐고 무엇을 할 수 있는지 |
| 참석 가능 / 불가 | 비어 있어요 / 일정이 있어요 |
| 참석 / 불참 / 거절 | 수락 / 다음에 |
| 스케줄, 이벤트 | 일정 |
| 가용 시간 | 비어 있는 시간 |
| 유저, 멤버님 | 멤버, 사람 이름 |
| 관리자, 고객센터 | 운영자 |
| 프리미엄, 업그레이드 | 플러스, 플러스로 |
| 보안, 안전하게 보호 | 기기에서만 열려요 |
| 지금 바로, 놓치지 마세요 | (쓰지 않음) |
